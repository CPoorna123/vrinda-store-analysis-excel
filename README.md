# 📊 Vrinda Store Data Analysis (Excel Project)

## 📌 Project Overview
This project analyzes Vrinda Store sales data to understand customer behavior, top-performing regions, monthly sales trends, and order performance.  
The goal is to help the business make data-driven decisions for sales growth.

## 📁 Dataset Details
- **File:** Vrinda Store Data Analysis.xlsx  
- **Contains:** Order details, customer details, sales performance & order status  
- **Rows:** ~1,000+  
- **Tools Used:** Microsoft Excel (Pivot Tables, Charts, Slicers, Dashboard)

## 🛠️ Skills Used
- Data Cleaning  
- Data Transformation  
- Pivot Tables  
- Pivot Charts  
- Dashboard Creation  
- Excel Formulas (SUMIFS, COUNTIFS, VLOOKUP, IF)  
- Slicers & Filters

## 📊 Key Insights

### **1️⃣ Monthly Sales Trend**
- Sales **increase significantly during March, June, and December**.
- Lowest sales occur at the beginning of the year.
- Helps understand seasonal buying behavior.

### **2️⃣ Sales by Gender**
- **Females contribute more to total sales** compared to males.
- Female customers show higher order frequency.

### **3️⃣ Top Performing States**
Highest number of orders come from:
- **Maharashtra**
- **Karnataka**
- **Uttar Pradesh**
- **Delhi**
These states have strong customer activity and higher conversions.

### **4️⃣ Order Status Analysis**
- Majority of orders are **Delivered**.
- Small percentage of:  
  - **Returned**
  - **Cancelled**
  - **Refunded**
- Helps evaluate delivery performance and customer satisfaction.

### **5️⃣ Sales by Age Group**
- Highest purchase activity is from **Adults (30–49 years)**.
- Teenagers contribute the lowest sales segment.

### **6️⃣ Channel Performance**
Top channels generating sales:
- **Amazon**
- **Flipkart**
- **Myntra**
Amazon leads in number of orders.

## 📈 Dashboard Features

## 🎯 Conclusion
The Vrinda Store analysis helps identify:
- Top customer segments  
- Profitable states  
- Best-performing channels  
- Seasonal ordering patterns  
- Areas to improve (returns/cancellations)
This dashboard can help in **better marketing strategy, inventory planning, and customer targeting**.
